Мой первый проект на Хекслете

## Команды Makefile

* 'make install' - устанавливает зависимости проекта (аналог 'npm install')
* 'make lint' - проверяет ошибки в логике и стиль форматирования НЕ ИЗМЕНЯЯ файл
* 'make lint-fix' - исправляет мелкие ошибки линтера и приводит к правильному форматированию
